A recipe for Astro sites: build to `dist`, verify that folder from the command line or in CI, and a small `astro:build:done` hook an Astro project can keep as its own file to run `seaworthy verify` on the output folder and fail the build on findings. The page covers the settings that change what the checks see — `build.outDir`, a `base` path read from `astro.config.*`, image optimization under `_astro/`, `_headers` and `_redirects` from the Netlify and Cloudflare Pages adapters, and server-rendered output — and states plainly that Seaworthy reads built output only, ships no Astro code, and adds no dependency.
