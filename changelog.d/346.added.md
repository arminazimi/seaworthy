`layout.target-size` reports an interactive element whose rendered touch target is smaller than the 24×24 CSS px minimum of WCAG 2.5.8. It runs only under `--rendered`: every page is measured at the phone, tablet, and desktop widths, one element is one finding naming its smallest box and the widths it failed at, and the inline-in-a-sentence, exactly-24×24, disabled, invisible, and off-screen cases are exempt. axe's own `target-size` rule is switched off in `a11y.axe` so one small target is never reported twice.
