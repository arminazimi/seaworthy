`seaworthy verify --rendered --evidence <folder>` now saves a PNG crop of the viewport around each rendered finding's element — the pixels that proved it — into the folder you name, and the finding carries an `evidence` field with the crop's relative path and the width it was taken at. Crops are named by the finding's fingerprint, so two runs of the same site write the same files; a run without the opt-in writes nothing and its report is byte-for-byte what it was before. (#350)
