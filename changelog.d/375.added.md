The Seaworthy pull-request comment now shows the trend over the recent runs: the Action reads the run summaries `verify` records in `.seaworthy/history` and adds one compact severity table (date, findings, errors, warnings, notes), oldest run first, above the comment's closing marker. Only runs recorded with the current run's `configHash` are comparable, so a run that verified a different configuration is dropped instead of plotted next to its neighbours; the newest 10 comparable runs are shown, dates are rendered from the stored UTC timestamps, and a runner with no history — or only one comparable run — gets exactly the comment body it got before, byte for byte. `packages/action/src/trend.ts` is the whole rule; the Action adds no new input and the report JSON is unchanged.
