The MCP server gained the `verify_site` and `verify_changed` tools: `verify_site` verifies a built site and returns the report JSON, the same JSON `seaworthy verify --format json` writes, and `verify_changed` returns that report with the findings outside the changed files left out, comparing with a git ref or with the last run. Both read the site's `seaworthy.config.json`, and the checks that need a browser or the network stay opt-in. (#77)
