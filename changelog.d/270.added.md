`docs/integrations/sveltekit.md` is a recipe for the SvelteKit static adapter: install `@sveltejs/adapter-static` in your own project, set `kit.adapter` with `pages: 'build'`, prerender every route so `npm run build` writes `build`, and verify that folder with `seaworthy verify build`. It covers the two things the generator cannot tell Seaworthy — `kit.paths.base` must be repeated as `basePath` or `--base`, because base-path detection reads Jekyll, Astro, Docusaurus, Hugo, and VitePress configs only — and what a `fallback` single-page-app shell means for the checks that read HTML on disk.
