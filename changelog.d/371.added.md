`i18n.parity` reports a `warning` for every language an hreflang cluster declares between its pages but no page of the cluster serves: the English page promises a German twin that the build never emits. Pages are grouped by their `rel="alternate" hreflang` links, the way `i18n.hreflang` reads them, so the set itself says which pages are translations; `x-default` is never a language, a language declared only on another host is never demanded offline, and a site can list an intentional gap under `checks."i18n.parity".options.untranslated`. The fix hint is manual, because translating a page is not a text edit. (#371)
