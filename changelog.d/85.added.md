`seaworthy init --agents`: a one-step adoption now also offers the verify instructions for the repo's own agent file. It picks `AGENTS.md` when it exists, else `CLAUDE.md`, else a new `AGENTS.md`, and prints one unified diff that appends a "Seaworthy verification" section — the real built-site folders, exit codes, `--fail-on`, `fix --dry-run` plus `git apply`, and the pre-alpha install line. The file is yours: init reads only the chosen one, writes nothing there, and gives no patch to a file that already carries the section, so applying it stays your deliberate move. (#85)
