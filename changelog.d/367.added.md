The Seaworthy Action takes a `markdown` input, one file or folder per line or comma, and forwards it to the CLI's `--markdown` flag, so a workflow can point the `md.*` checks at sources that live outside the built site folder — a `README.md` or `docs/` at the repository root, for instance. An empty input changes nothing: the Action runs exactly as it did before, and the Markdown checks keep walking the built folder. (#367)
