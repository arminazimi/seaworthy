`seaworthy verify --format html` now draws a **Trend** section from the run summaries already stored in `.seaworthy/history`: an inline SVG of findings per run over the last ten readable runs, plus a compact table of those runs (timestamp, root, findings, errors, warnings, notes). It renders nothing on a fresh folder, after a single run, or with `--no-history` — one point is not a chart — and skips any truncated or hand-edited record instead of failing. The trend is HTML-only presentation: the report JSON and every machine-readable format stay byte-identical, and the page still loads no external asset or script. (#374)
