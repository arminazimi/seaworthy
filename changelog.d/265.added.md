`seaworthy explain <check-id>` prints a check's docs page — the contract at `docs/checks/<check-id>.md` — in the terminal: what the check reports, why it matters, the rule, the fix with examples, its options, and the standards. The id must be one the registry knows; an unknown or missing id is a usage error (exit 2). An install that does not ship the docs pages shows the check's own metadata instead of crashing. (#265)
