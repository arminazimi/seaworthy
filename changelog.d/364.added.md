`md.images` reports images inside Markdown files that point at a file the verified root does not contain, and images written with no alt text, both located at the exact source line. It reads any Markdown files found in the verified folder, needs no browser and no network, and covers both syntaxes: `![alt](src)` and a raw HTML `<img>` in the source. An empty `alt=""` or a decorative `![](src)` passes; a missing `alt` attribute on an `<img>` is an `error`, with the same exemptions as `images.alt`. It suggests an exact text edit when one file in the site carries the missing target's basename, or when the placeholder alt can be anchored on the tag. (#364)
