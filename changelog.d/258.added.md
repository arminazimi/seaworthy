Codex users can wire the Seaworthy MCP server into a session with a config snippet they paste: `plugins/seaworthy-codex/` carries `codex-config.toml` (the `[mcp_servers.seaworthy]` section Codex reads from its own config), `bundle.json` recording the server name, command, args, launcher, tools and install facts, and a README with the only install paths that work today — a built checkout, or a git reference pinned to a full commit SHA, since `@seaworthy/*` is not published and no release tag exists. It reuses the launcher the Claude Code plugin ships instead of copying it, and it bundles no Skills: no `SKILL.md` exists in this repository yet, so the bundle's skill list is empty and a test pins that it can neither lead nor lag `skills/`. Codex has no plugin marketplace, so nothing here claims one (#258).
