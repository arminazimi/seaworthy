`quality.font-count` reports a page that pulls in more distinct font files than it should. The check walks each page's linked stylesheets and inline `<style>` blocks, counts the `.woff`, `.woff2`, `.ttf`, `.otf`, and `.eot` files the build actually serves — deduplicated by site path — and warns once per page above the maximum, which is 6 unless `checks."quality.font-count".options.max` says otherwise. The finding lists the offending fonts in sorted order, so an agent knows exactly which files to drop, subset, or fold into a variable font. No browser, no network. (#332)
