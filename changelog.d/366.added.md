`seaworthy verify --markdown README.md docs/` names the Markdown sources the `md.*` checks read, for projects whose README and documentation live outside the built folder. Each path is a `*.md`/`*.markdown` file or a directory walked for them; the named files replace the site-folder walk for that run, links between them keep resolving, and findings stay relative to the folder the command ran in — never absolute. A missing path or a non-Markdown file is a usage error (exit 2); a directory holding no Markdown adds nothing. Without the flag every run is byte-identical to before. (#366)
