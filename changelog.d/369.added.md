`i18n.x-default` reports a `warning` when a multilingual site — one whose `hreflang` declarations cover two or more languages — has a page that takes part in an alternate set but declares no `x-default` entry, and when a page declares more than one. The fix hint offers the exact `<link rel="alternate" hreflang="x-default">` tag with a placeholder `href`, marked as needing input, because only a person knows which page is the language fallback. Sites with a single language report nothing. (#369)
