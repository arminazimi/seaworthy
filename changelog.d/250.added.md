The MCP server gained the `diff_reports` tool: it compares two stored Seaworthy report files — as written by `seaworthy verify --format json`, paths relative to the workspace — and returns the same new/fixed/unchanged JSON `seaworthy diff before.json after.json` prints. The comparison is verify's own fingerprint matching from `packages/verify/src/diff.ts`; the MCP layer adds no second matching rule, reads no site, and stays offline. A missing or damaged report file is a clean tool error naming the file, never invented counts. (#250)
