Seaworthy's own test suite can now serve a built site over real HTTP from inside a test: a folder of fixture bytes handed out as they are stored, on a `127.0.0.1` port the operating system chose, with the statuses, headers and redirects a test states and nothing invented - no body the fixture does not name, nothing served from outside the folder, nothing evaluated. It is how the live checks that follow get a deployed site without a network connection, and every socket it opens is closed before the run ends, on Windows, Linux and macOS alike. (#316)
