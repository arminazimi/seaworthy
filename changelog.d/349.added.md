`layout.reflow` renders each page at the 320 CSS px viewport WCAG 1.4.10 fixes and reports, as a `warning`, the outermost fixed-size box that stays wider than the viewport so the document must be panned sideways as well as scrolled, naming the element's selector, opening markup and measured width. The success criterion's two-dimensional exceptions are honoured: a `<table>` passes as tabular data, and so does content inside its own non-root scroll container; the sideways-scroll observation stays with `layout.horizontal-overflow` and a clipped element with `layout.text-clipped`. It is a rendered check, opt-in under `--rendered`, offline over `file://` URLs with remote requests refused. (#349)
