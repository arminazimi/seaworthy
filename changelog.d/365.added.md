`links.external` now reads the Markdown files in the verified folder too: when the check is enabled with `--network`, distinct `http(s)` links in Markdown sources go through the same probe and the same per-host and overall request pools as the HTML links, so each URL is still fetched once per run and bot-protected or rate-limited answers stay skipped, not reported. A Markdown finding is located at the link's line in the `.md` source and carries the same fix hint as its HTML counterpart. No new check ID and no contract change: without `--network` nothing is read or fetched. (#365)
