Every check now has a generated reference page under `docs/checks/reference/`, one per check in the catalog (all 80 built-in checks plus the two suppression checks). Each page is composed by `tools/gen-check-reference.mjs` from the check's own metadata — ID, title, default severity, needs with their `--rendered` / `--network` opt-in gates, standards, source module — and the hand-written prose page in `docs/checks/`, embedded verbatim; no fact gains a second home. Regenerate with `npm run build && npm run reference:build`; `npm run check` now fails in `--check` mode when a page drifts from either source, is missing, or is stale. (#108)
