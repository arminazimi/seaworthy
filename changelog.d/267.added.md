Added `docs/integrations/eleventy.md`, a recipe for verifying an Eleventy site: build to `_site` with `npx @11ty/eleventy`, then `seaworthy verify _site`, with a GitHub Actions job and the composite Action. It states plainly that Seaworthy reads only built output and does not read Eleventy's config, so a site served from a subpath sets `basePath` in `seaworthy.config.json` or passes `--base`, and covers what a project's own settings change for the checks — permalink style against `links.internal`, `eleventyNavigation` and collections feeding `quality.orphans`, images reaching `_site` only through passthrough file copy for `assets.missing`, `_headers`/`_redirects` checked only when added, and the offline-by-default rule.
