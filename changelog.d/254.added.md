The MCP server can now be reached over HTTP as well as stdio. `seaworthy-mcp` still starts on stdio by default; `seaworthy-mcp --http` serves the same `list_checks`, `verify_site`, and `verify_changed` tools over the Streamable HTTP transport on `/mcp`. It binds loopback (127.0.0.1, port 3333) unless the operator names another `--host` and also passes `--allow-non-loopback`, and it verifies only the folder given by `--root`, so a call that names a site outside it is refused instead of run. The transport has no authentication: it is a local developer convenience, not a hosted server. (#254)
