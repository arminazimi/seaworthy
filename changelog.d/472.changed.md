Adding a check or an output format no longer edits a shared index: create a module under `packages/verify/src/checks/` or `src/formats/` (a format exports one `render` function), run `npm run build` and `node tools/gen-registries.mjs`, and the generated registries collect it — checks sorted by check ID, formats by format ID, so parallel PRs stop conflicting on `index.ts` (#472).
