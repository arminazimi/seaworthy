`md.anchors` reports a `#fragment` in a Markdown link that no heading in the file it points at has, using GitHub's slug rules and matching anchors without regard to case, located at the exact source line. Fragment-only links are checked against their own file, and a link whose target file is missing stays with `md.links`, so one dead link yields one finding. It reads the Markdown graph the run already built, needs no browser and no network, and suggests the closest anchors: an exact text edit when the only difference is a heading-dedup suffix, otherwise the file and anchor to write.
