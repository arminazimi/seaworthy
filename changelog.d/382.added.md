`readability.webmcp` reports, as a note, each WebMCP tool registration an agent could not use: a name outside the draft's 1-to-128 characters of letters, digits, `-`, `_` and `.`, a tool with no description, an `inputSchema` that is not a JSON Schema object of type `object`, a name two tools share, and a page whose own source registers tools while the list its model context answers with is empty, holds only a frame's tools, or does not answer at all. The check reads that list — the same view an agent builds from — in a real browser under `--rendered`, and it never calls a registered handler, because site code is untrusted and a draft standard gets notes rather than errors. A browser without WebMCP, which is most of them while the Chromium origin trial runs, skips the check with a reason instead of pretending it passed. (#382)
