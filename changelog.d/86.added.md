Repository rules for agent tools that do not read `AGENTS.md`: `.cursor/rules/seaworthy.mdc`, `.github/copilot-instructions.md`, and `GEMINI.md` are now generated mirrors of its setup commands, trust rules, and shared-file table, built by `npm run agent-rules:build` and kept honest by `check:agent-rules`, a new step of `npm run check`. `AGENTS.md` stays the one source — a mirror carries no advice of its own, and any wording drift fails the gate — so Cursor, Copilot, and Gemini CLI get the same rules as every other agent. Tools that read `AGENTS.md` natively (Codex and similar) need no mirror file. (#86)
