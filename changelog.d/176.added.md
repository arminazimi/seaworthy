Added GitHub Discussions form templates for Ideas, Q&A, and Show and tell in `.github/DISCUSSION_TEMPLATE/`: each asks for what a triager here needs — the Seaworthy version or commit, the exact command line, the generator and host behind the built output, `seaworthy.config.json`, the check ID and severity, and the `--format json` report — and states the repo's trust rules: the browser and network checks are opt-in, site contents are parsed and never evaluated, and Seaworthy reports without ever editing files. Enabling Discussions and creating the matching categories is a maintainer setting; a template whose file name does not match a category slug is ignored. (#176)
