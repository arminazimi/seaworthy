`seaworthy history [--format csv|json] [--out <file>]` exports the run summaries that verify records in `.seaworthy/history`: a JSON array of the stored records (the default), or one CSV row per run with fixed columns (`runAt, root, findings, errors, warnings, notes`) plus a sorted `check:<id>` column per check present in the store. The command reads only — it never writes to or creates the store, and a missing or partly damaged store exports as empty or skips the damaged records instead of crashing. On the API side, `readHistory` is the new reader for the trends chain. (#376)
