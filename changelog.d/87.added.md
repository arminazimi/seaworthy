The repository now carries a Claude Code plugin: `.claude-plugin/marketplace.json` makes it a Seaworthy marketplace and `plugins/seaworthy` bundles the MCP server (`list_checks`, `verify_site`, `verify_changed` — exactly what the server registers today; planned tools stay unadvertised). Because `@seaworthy/*` is not on npm and no release tag exists, the plugin starts the server through a dependency-free launcher that spawns a built `packages/mcp/dist/src/main.js` (or `$SEAWORTHY_MCP_SERVER`) and otherwise exits with a fix hint instead of pretending to work. Skills join the bundle once their `SKILL.md` files exist in the repository. (#87)
