## Goal
Prove the Persian checks are trustworthy on real sites before release.

## Steps
1. Pick 50 public Persian pages (news, government, shops, docs, blogs).
2. Run the `rtl.fa.*` checks; a Persian reader marks each finding right or wrong.
3. File an issue for every rule over 2% false positives.

## Done when
- [ ] The table of rule, findings, and false positives is in this issue.
