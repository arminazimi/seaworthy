# a11y.duplicate-id

The same `id` is used on more than one element in a page.

## Why it matters

An `id` is meant to name exactly one element. Everything that points at an element by id, such as `href="#section"`, `<label for>`, `aria-labelledby`, and `aria-describedby`, reaches only the first element with that id. A second, third, or fourth copy is ignored, so a label can end up naming the wrong field and a skip link can jump to the wrong place. Components that are pasted in more than once, such as inline SVG icons with gradients or form fields with a fixed id, are the usual cause.

## What it checks

Every element with a non-empty `id` that repeats one used earlier in the same page. The first element is accepted; each later repeat is reported at its `id` attribute. Pages are compared separately, so the same id on two different pages is fine. Empty ids are ignored.

## How to fix

```html
<!-- before -->
<input id="email" name="billing-email">
<input id="email" name="shipping-email">

<!-- after -->
<label for="billing-email">Billing email</label>
<input id="billing-email" name="billing-email">
<label for="shipping-email">Shipping email</label>
<input id="shipping-email" name="shipping-email">
```

Rename the repeats and every reference to them. There is no automatic edit, because the report cannot tell which references belong to which copy.

## Options

None.
