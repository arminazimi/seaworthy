# a11y.iframe-title

An `iframe` has no accessible name describing its embedded content.

## Why it matters

Screen reader users need a name for each frame so they can decide whether to enter it.

## What it checks

Visible, non-presentational iframes need a non-empty `title`, a non-empty `aria-label`, or `aria-labelledby` referencing an element on the same page with text. HTML entities are decoded and whitespace-only names do not count. Missing references and references to empty elements do not supply a name.

The check skips frames hidden by `hidden` or `aria-hidden="true"`, including on an ancestor, and frames with `role="presentation"` or `role="none"`.

This static check does not fetch frame URLs or judge whether an existing name is descriptive.

## How to fix

```html
<iframe src="/map.html" title="Office location map"></iframe>
```

Choose a title that describes the embedded content. The report provides a manual fix hint because the checker cannot infer that content.

## Options

None. Default severity: `error`.

## Standards

- [WCAG 4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html)
- [Technique H64: Using the title attribute of the frame and iframe elements](https://www.w3.org/WAI/WCAG22/Techniques/html/H64)
